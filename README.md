# forcastly  -🌤️ Weather App
A responsive weather website showing live condition and hourly forcast.

A simple and modern weather application that allows users to check the **current weather and upcoming forecast** for any city worldwide.  
This project is built using **HTML, CSS, and JavaScript** and uses the **OpenWeatherMap API** to fetch real-time weather data.

# 🚀 Features

- Search weather by city name  
- Shows current temperature in Celsius (°C)  
- Displays weather condition with icon  
- Shows humidity and wind speed  
- Upcoming weather forecast for the next few hours  
- Clean and responsive user interface  

# 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript  
- OpenWeatherMap API  

# 📦 Setup & Usage

1. Get an API Key
- Visit https://openweathermap.org/api  
- Create a free account  
- Copy your API key from the dashboard  

2. Add the API Key
Open `app.js` and replace:

const API_KEY = 'your_api_key_here';

3. Run the Project
Open index.html in your browser
